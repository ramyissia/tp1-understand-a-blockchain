Debugging challenge - a validator that only checks links
======================================================================
  block 1 data changed to 'Alice -> Bob: 100', hashes left as they were
  buggy_is_valid(chain): True   <- accepts the forgery
  chain.is_valid():      False
    reason: block 1: stored hash does not match a fresh calculation (its data changed)
  Bug: buggy_is_valid compares two STORED values (previous_hash and
  hash). Nobody recomputes block 1's hash from its data, so the edit
  is invisible. Fix: also require block.hash == block.calculate_hash().
